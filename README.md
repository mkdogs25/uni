# Weft

Weft is a small personal language that combines markup, styling and logic in
one indentation-based, Python-like file, and compiles to plain HTML, CSS and JS.

- **Try it:** https://mkdogs25.github.io/uni (browser IDE; the compiler runs
  in your browser via Pyodide)
- **Design:** `docs/SPEC.md`, decisions in `docs/adr/`
- **Examples:** `examples/`
- **Status:** spec approved; compiler phases in progress (see `docs/JOURNAL.md`).
